F1 Reaktionstest

Realistische Startampel mit 5 roten Lichtern — reagiere, wenn alle Lichter ausgehen (GO). Space / Klick / Touch verwenden.

Tip: Trainiere deinen Start wie in der Formel 1
Bereit?
Drücke "Start" oder Leertaste
Anleitung: Nach Klick auf Start leuchten die 5 roten Lichter nacheinander auf. Sobald alle fünf Lichter an sind, gehen sie nach kurzer, zufälliger Verzögerung gleichzeitig aus — das Signal zum Reagieren. Wenn du vor dem Erlöschen reagierst, wird ein False Start gewertet.
