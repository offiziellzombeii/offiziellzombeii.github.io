Data Pack Builder

Make a data pack for the championship mode from open data: the results of any season since 1950 from the Jolpica F1 API and circuit layouts from the f1-circuits collection. Then import it in Race Control (Championship → Data packs). ← Back to Race Control

Step 1 · Season

Load a season

Calendar, teams and drivers of one year with the same statistics as the built-in pack: average finish and grid position, head-to-head against the team mate, retirements.

Step 2 · Circuit layouts

Check the new circuits

Circuits that are not in a pack yet get their layout from the f1-circuits collection (MIT licence) – or, if it is not there, from the race track mapped in OpenStreetMap around the circuit (the loop closest to the expected length; start line next to the pit lane). Street circuits that are normal roads today are often not mapped as a race track: then load a layout file (GeoJSON, GPX or KML – e.g. drawn on geojson.io). Check every one: the white line is the start / finish line, the arrow shows the direction of the race. The speed profile comes from physics on the layout, calibrated to the real pole time of the season (1.04 × pole, like the circuits with telemetry). If that time looks wrong (a wet qualifying), enter a dry reference lap.
